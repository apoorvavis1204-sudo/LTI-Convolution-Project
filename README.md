 LTI Convolution Project
Objective
To simulate the convolution of signals in a Linear Time-Invariant (LTI) system using Python.

Technologies Used
- Python
- NumPy
- Matplotlib

 Project Files
- `convolution_lti.py` – Python source code.
- `convolution_graph.png` – Generated convolution graph.
- `LTI-Convolution-Project Report.pdf` – Project report.

 Output
The convolution output is:
`[1 3 4 3 1 0]`

 Conclusion
The project successfully demonstrates linear convolution and the output response of an LTI system.
